# Database Layer

This folder contains all database-related logic for the concert ticket app.

- Drizzle ORM setup
- PostgreSQL connection
- Schemas & migrations
- Repositories

## Structure
- `schema/` — Drizzle schema definitions
- `migrations/` — Migration files
- `connection.ts` — DB connection logic
- `repositories/` — Data access logic
